# T4: Radial menu

**Depends on:** T1, S2

## Scope

- Production version of the S2 overlay: one slice per workspace with icon and
  name, center dead zone, highlight follows pointer angle, Esc cancels, empty
  state hint.
- Slice-selection math as a pure, unit-tested function.
- Driven by the gesture state machine (show on hold, select on release; a pick on a busy desktop goes to the confirm flow); until
  T3 lands, drive it through the D-Bus debug methods.

## Acceptance

- Selection math tests pass; the user signs off on look and feel on the live
  session in light and dark themes.

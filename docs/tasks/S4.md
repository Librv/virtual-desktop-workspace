# S4: Spike, launching and window matching

**Depends on:** T0b

## Questions

1. Launch apps from a `.desktop` id with extra args via
   `KIO::ApplicationLauncherJob`. Which process id do we get back?
2. For Konsole (both normal and "run all windows in a single process"),
   Dolphin and Firefox: does the new window's pid match, and does its
   `desktopFileName` match the `.desktop` id?
3. Does first-come-first-served matching by app id hold up when 3 windows of
   the same app launch at once, and when an unrelated window of the same app
   opens during setup?
4. Is there an activation or startup token visible to a KWin script that would
   make matching exact?

## Output

`docs/spikes/S4.md` with a recommended matching strategy and timeouts.

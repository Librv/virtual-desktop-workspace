# S3: Spike, KWin script placement via events

**Depends on:** T0b

## Questions

1. Load and unload a JS KWin script at runtime through `org.kde.kwin.Scripting`
   and pass it data (e.g. pending placements) after loading. Options: script
   config, re-running a small script per request, or the script calling
   `callDBus` to fetch work from the daemon.
2. On `workspace.windowAdded`, is the window's app id (`desktopFileName`,
   `resourceClass`) already set, and does setting `frameGeometry` right away
   stick, or does the app resize itself afterwards?
3. Report results back to the daemon with `callDBus`.
4. List current-desktop windows with geometry and app id (for T6).
5. Port the emptiness check and usable-area query from `setup-workspace.sh`.

## Output

`docs/spikes/S3.md` plus a throwaway script under `spikes/S3/`, tested in the
nested session.

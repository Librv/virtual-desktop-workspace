# T5: KCM (System Settings page)

**Depends on:** T1. **Owns:** `src/kcm/` only (its own `CMakeLists.txt`,
plugin, QML and tests). Do not edit any file outside `src/kcm/`; link
`vdwcore` for loading but do not change it.

Design: `docs/ARCHITECTURE.md` "Config" (the file format and validation
rules are fixed) and "KCM".

## Scope

- QML KCM `kcm_vdw` (KCMUtils `KQuickConfigModule`, Kirigami): list,
  add, rename, delete and reorder workspaces; set the default; edit icon;
  edit slots (app as `.desktop` id with an app picker if KF6 offers a simple
  one, extra args, geometry x/y/width/height as fractions).
- A config writer in `src/kcm/` that produces exactly the ARCHITECTURE
  format; new workspace ids are slugs derived from the name, unique.
- Save writes `vdwrc` and calls `io.github.librv.vdw` `/Manager`
  `ReloadConfig` (ignore the error when the daemon is not running).
- "Save current desktop as workspace" button calls `CaptureCurrentDesktop`
  and shows the reply (it returns "not implemented" until T6).
- A button that opens the Shortcuts page (`kcm_keys`) instead of a key
  editor.
- Visual slot editor (drag rectangles on a screen preview) is a stretch goal;
  skip it unless the rest is done.

## Acceptance

- Unit test: writer output loads back through `vdwcore`'s `Config` with the
  same workspaces (round trip), including ids, ordering and geometry.
- In the nested session: `kcmshell6 kcm_vdw` (with the build dir on
  `QT_PLUGIN_PATH`) opens; a screenshot of the page with a test config is
  saved under `docs/spikes/T5/`.

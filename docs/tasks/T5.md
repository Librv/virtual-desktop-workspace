# T5: KCM (System Settings page)

**Depends on:** T1

## Scope

- QML KCM: list, add, edit, delete workspaces; set default; edit app slots
  (app picker, args, position); link to Shortcuts for key editing.
- Writes the same config as T1 and asks the daemon to reload.
- Visual slot editor (drag rectangles on a screen preview) is a stretch goal.

## Acceptance

- `kcmshell6 <name>` opens the page; edits survive a daemon restart.

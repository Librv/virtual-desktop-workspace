# S2: Spike, radial overlay on LayerShellQt

**Depends on:** T0b

## Questions

1. Can a full-screen transparent LayerShellQt surface on the overlay layer
   receive pointer motion while keyboard interactivity is `none` (so it does
   not steal focus)?
2. How to get the pointer position at the moment the menu opens on Wayland
   (`QCursor::pos()` is unreliable): first hover event, KWin's
   `workspace.cursorPos`, or something else?
3. While the overlay is shown, does the release of the held shortcut still
   reach `kglobalaccel` (combine with S1's test daemon)?
4. Show and hide latency: keep the surface alive and hidden, or create it on
   demand?
5. Plasma theme colors in the QML (Kirigami theme) render correctly in light
   and dark themes.

## Output

`docs/spikes/S2.md` plus a throwaway QML/C++ prototype under `spikes/S2/` that
draws a few slices and prints the selected one on release.

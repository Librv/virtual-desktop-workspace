# T6: Save current desktop as workspace

**Depends on:** T1, S3

## Scope

- KWin script lists current-desktop windows with geometry and app id; daemon
  converts geometry to fractions of the usable area and writes a new workspace.
- Exposed over D-Bus, in `vdwctl`, and as a button in the KCM (coordinate with
  T5).
- Windows whose app id has no matching `.desktop` file are skipped and
  reported.

## Acceptance

- In the nested session: arrange 3 Konsoles, capture, close them, open the new
  workspace, and the windows come back at the same positions (within a few
  pixels).

- `docs/spikes/S3.md`: `listWindows()` in `spikes/S3/placer.js` run as a one-shot script; store fractions of the usable area, app id from `desktopFileName`, skip and report windows without one.

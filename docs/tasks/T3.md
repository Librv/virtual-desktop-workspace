# T3: Shortcuts, gesture state machine, OSD

**Depends on:** T1, S1

## Scope

- Gesture state machine as specified in `SPEC.md` (tap, hold, confirm,
  timeout, confirm after a radial menu pick), pure logic with an injectable clock, unit-tested thoroughly.
- Register Ctrl+Meta+D and per-workspace shortcuts with KGlobalAccel; keep
  them in sync when config changes.
- OSD messages via Plasma's osdService.

## Acceptance

- Unit tests cover every transition in the spec.
- The user confirms tap, hold and confirm on the live session.

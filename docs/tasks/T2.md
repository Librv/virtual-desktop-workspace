# T2: Launch and placement engine

**Depends on:** T1, S3, S4

## Scope

- Turn a workspace into launches plus pending placements; layout math from
  fractions to pixel rectangles of the usable area (unit-tested).
- Emptiness check before opening; return "busy" to the caller instead of
  launching.
- Matching and timeouts per S4; report partial failures.

## Acceptance

- In the nested session, `vdwctl open "3 Konsoles"` on an empty desktop places
  3 Konsoles at the configured slots; on a busy desktop it returns "busy" and
  launches nothing; a forced open places them anyway.

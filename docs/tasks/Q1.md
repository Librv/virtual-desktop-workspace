# Q1: Bash script busy-desktop confirm (quick win)

**Depends on:** T0. Independent of everything else; gets replaced by T3.

## Goal

Give the user the confirm flow now, in `setup-workspace.sh`.

## Scope

- If the current desktop is not empty: write a timestamp to a state file under
  `$XDG_RUNTIME_DIR`, show a Plasma OSD message ("Desktop not empty. Tap D
  again to set up here.") via `qdbus6 org.kde.plasmashell /org/kde/osdService`,
  and exit.
- If a press arrives within 2 s of that timestamp: delete the state file and
  set up on the current desktop alongside the existing windows.
- Leave the empty-desktop path as it is.

## Acceptance

- Busy desktop: first press shows the message and launches nothing; second
  press within 2 s sets up; a press after 2 s shows the message again.
- Tested in the nested session where possible; the real shortcut is tested by
  the user.

# T1: Daemon skeleton, config, D-Bus API, vdwctl

**Depends on:** S1, S3

## Scope

- `vdwd` executable: `QGuiApplication`, `KDBusService` (unique), loads the
  KWin script from S3 at startup.
- Config schema in KConfig (`~/.config/vdwrc`), with a parser and validation;
  record the schema in `ARCHITECTURE.md`.
- D-Bus API: list workspaces, open workspace by name, reload config, plus
  debug-only methods to inject gesture events. Record names in `DECISIONS.md`.
- `vdwctl` CLI over that API.
- Unit tests for config parsing.

## Acceptance

- `vdwctl list` prints workspaces from a test config; `vdwctl open <name>`
  reaches the daemon (placement itself is T2).

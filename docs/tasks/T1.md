# T1: Daemon skeleton, config, D-Bus API, vdwctl

**Depends on:** S1, S3 (done)

Design is fixed in `docs/ARCHITECTURE.md` (sections Config, D-Bus API) and
`docs/DECISIONS.md` (rows 12 to 14). Do not change names or formats; report
back if something there does not work.

## Scope

- Source layout: `src/lib/` (static library `vdwcore`, no GUI, no D-Bus:
  config model and parser), `src/daemon/` (`vdwd`), `src/vdwctl/`,
  `autotests/`. Wire them into the top-level `CMakeLists.txt`.
- `vdwcore`: `Workspace` and `Slot` value types, `Config` loader from a
  `KSharedConfig`/file path with the validation rules in ARCHITECTURE
  (invalid entries skipped with a warning, ids `[a-z0-9-]+`, geometry
  fractions in 0..1, sorting by `Order` then `Name`), and a JSON
  serializer used by `ListWorkspaces`.
- `vdwd`: `QGuiApplication` with `KDBusService` (unique), registers service
  `io.github.librv.vdw` and the `/Manager` and `/Script` objects with the
  methods listed in ARCHITECTURE. In T1:
  - `ListWorkspaces` and `ReloadConfig` are real.
  - `OpenWorkspace` validates the id and returns `"error: not implemented"`
    for known ids (T2 fills it in); unknown ids return `"error: unknown
    workspace"`.
  - `CaptureCurrentDesktop` returns `"error: not implemented"` (T6).
  - `/Script` methods exist and log their arguments; `ClaimWindow` returns
    `""`.
  - `/Debug` is registered only with `--debug` and logs calls (T3 wires it).
  - Config path overridable with `--config FILE` (tests use this).
- `vdwctl`: `list`, `open <id> [--force]`, `capture <name>`, `reload`; prints
  the reply, exit code 1 on `error:` replies or D-Bus failure.
- D-Bus `.service` file for `io.github.librv.vdw` (install rule only; not
  installed system-wide in this task).
- Unit tests for the config parser (valid file, each invalid case, ordering,
  JSON output).
- An integration test (skips when no nested session is reachable) that starts
  `vdwd --config <test file>` inside the nested session and checks
  `vdwctl list` and `vdwctl open` replies.

## Not in scope

Launching and placement (T2), shortcuts and the gesture machine (T3), the
radial menu (T4), the KCM (T5), capture (T6), loading the KWin script.

## Acceptance

- `cmake --preset dev && cmake --build --preset dev && ctest --preset dev`
  passes, with the parser tests.
- In a nested session: `vdwctl list` prints the workspaces of a test config;
  `vdwctl open <known id>` reaches the daemon and prints the not-implemented
  reply; unknown id gives exit code 1.
